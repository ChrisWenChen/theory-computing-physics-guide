# 从零开始：理论/计算物理环境配置与软件安装指南

**Computing Environment Setup and Software Guide for Computational / Theoretical Physics**

---

这是一份面向计算物理、理论物理学生和科研初学者的计算环境配置与软件安装指南。它覆盖 **macOS、Ubuntu 和 Windows** 三个平台，内容从终端、包管理器、SSH、Git、编辑器、Python 环境开始，逐步延伸到 C/C++/Fortran、Make/CMake、MPI/OpenMP、高性能数值库、远程访问、知识管理和科研协作。

每一章都尽量回答四个问题：**为什么需要它、它是什么、如何安装、如何确认自己真的装好了**。

---

## 目标读者

- 本科生
- 刚开始进组的研究生
- 有一点编程经验但没有系统科研环境训练的人
- 需要在 macOS / Ubuntu / Windows 上搭建科研工作流的人

## 学完之后你能做到什么

- 理解科研计算所需的基本计算机知识
- 熟悉 macOS / Ubuntu / Windows 的差异
- 使用终端、包管理器、SSH、Git 和编辑器
- 在本地和服务器上安装并测试常用科研软件
- 使用 Python / C / C++ / Fortran 做基础数值计算
- 理解 MPI / OpenMP / BLAS 等高性能计算概念
- 初步具备"读懂别人代码、组织自己项目、使用 AI 辅助科研编程"的能力
- 建立文档、笔记、文献管理、同步和备份习惯

## 设计原则

每章都包含四部分：

1. **动机 Motivation** — 为什么这一章重要
2. **介绍 Introduction** — 核心概念是什么
3. **安装 / 配置 Installation / Setup** — 在三个平台上怎么做
4. **测试 Test / Verification** — 如何确认安装成功

## 常见学习误区

:::caution 常见误区
- **"我先把所有东西都装好再开始学"** — 不需要。按需安装，边学边装。
- **"我要先学完 Python 再学其他"** — 环境配置和语言学习可以并行。
- **"Windows 不能做科研"** — 可以，用 WSL 或 scoop 都行。
- **"直接复制命令就行了"** — 理解比复制更重要，否则遇到问题时无法排查。
- **"AI 可以替我学"** — AI 是助手，不是替代品。你需要理解它在做什么。
:::
