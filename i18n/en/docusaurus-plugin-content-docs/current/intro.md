# From Scratch: Computing Environment Setup and Software Installation Guide for Theoretical/Computational Physics

**Computing Environment Setup and Software Guide for Computational / Theoretical Physics**

---

This is a computing environment setup and software installation guide for students and beginning researchers in computational physics and theoretical physics. It covers **macOS, Ubuntu, and Windows**, starting from the terminal, package managers, SSH, Git, editors, and Python environments, and gradually extending to C/C++/Fortran, Make/CMake, MPI/OpenMP, high-performance numerical libraries, remote access, knowledge management, and research collaboration.

Each chapter strives to answer four questions: **Why do you need it, what is it, how to install it, and how to verify that it's actually installed correctly**.

---

## Target Audience

- Undergraduate students
- Graduate students who have just joined a research group
- People with some programming experience but no systematic training in research computing environments
- People who need to set up a research workflow on macOS / Ubuntu / Windows

## What You Will Be Able to Do After Completing This Guide

- Understand the fundamental computer science knowledge required for research computing
- Be familiar with the differences between macOS / Ubuntu / Windows
- Use the terminal, package managers, SSH, Git, and editors
- Install and test commonly used research software on local machines and servers
- Perform basic numerical computations using Python / C / C++ / Fortran
- Understand high-performance computing concepts such as MPI / OpenMP / BLAS
- Develop the initial ability to "read others' code, organize your own projects, and use AI-assisted research programming"
- Establish habits for documentation, note-taking, reference management, syncing, and backups

## Design Principles

Each chapter contains four parts:

1. **Motivation** — Why this chapter matters
2. **Introduction** — What are the core concepts
3. **Installation / Setup** — How to do it on three platforms
4. **Test / Verification** — How to confirm the installation was successful

## Common Learning Pitfalls

:::caution Common Pitfalls
- **"I'll install everything first before I start learning"** — No need. Install as needed, learn as you go.
- **"I need to finish learning Python before anything else"** — Environment setup and language learning can proceed in parallel.
- **"You can't do research on Windows"** — Yes you can, using WSL or scoop.
- **"I can just copy and paste commands"** — Understanding is more important than copying; otherwise you won't be able to troubleshoot when problems arise.
- **"AI can learn for me"** — AI is an assistant, not a replacement. You need to understand what it's doing.
:::
